Welcome to FoxQuiz

An intelligent, highly engaging, and child-safe exam preparation application powered by Google ADK 2.0 & Gemini 2.5 Flash.

The Problem with Study Tools

Traditional digital test prep falls short in three fundamental areas, making learning tedious and sometimes unsafe for young learners.

📖

Dry, Rigid & One-Size-Fits-All

Static questionnaires that do not adapt to a student's grade (Grades 5-12) or actual learning progress.

🛡️

Unchecked, Dangerous Content

Standard open-ended LLMs run the risk of generating inaccurate facts or child-inappropriate topics.

👤

Severe Privacy & PII Leakage

Most AI interfaces fail to prevent children from uploading private data (PII) or school credentials.

Why Choose AI Agents?

Security First

Autonomous Input Scanning

Unlike standard chatbots, our agents intercept queries locally. An IP Ban Sheriff detects PII, shields identities, and maintains extreme database guardrails automatically.

Quality First

Self-Correction Loop

No more AI hallucinations. The critique loop tests answers against real grade-level curricula, automatically regenerating questions if they fail strict pedagogical standards.

User First

Adaptive Mascot Pedagogy

Our agents maintain context state. Choosing different mascot buddies (Felix, Olivia, Dino) dynamically shifts the vocabulary, explanations, and encouraging hints.

How FoxQuiz Was Built — Design & Setup

01

Scaffold & Setup

Install necessary tools and skills, prompt Antigravity to set up the Google Cloud Environment, and use agents-cli to scaffold a new ADK 2.0 graph workflow agent project.

02

Behavior Spec

Compose a thorough Markdown specification in specs/my_spec.md mapping out the agent purpose, YAML and Pydantic data schemas, security guardrails, and detailed Gherkin behavioral rules.

03

Align & Interview

Trigger /grill-me with Antigravity to run an interactive alignment interview, identifying hidden edge cases and detailing the active mascot state-machine before writing code.

How FoxQuiz Was Built — Construction & Deploy

04

Build & Lint

Once you agree on the implementation plan, ask Antigravity to build the app. Iterate on new features and run strict agents-cli lint checks to verify format, code quality, and security guidelines.

05

Verify & Deploy

Verify execution using agents-cli playground. Obtain explicit human confirmation, and seamlessly deploy the child-safe multi-agent application to Cloud Run via agents-cli deploy.
